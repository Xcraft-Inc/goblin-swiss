**goblin-swiss** brings Swiss domain logic to the Goblin actor ecosystem — with a clear, local-first model of the entities and specifics that make Switzerland unique.

It provides a proud, pragmatic foundation for working with Swiss administrative concepts (like _Commune_ and _Canton_), identifiers, formats, and conventions — packaged as clean, reusable actors you can plug into your apps.

Built for Swiss software, by people who care about getting Switzerland right. 🇨🇭
